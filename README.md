# Grind Street - Pre-entrega

Proyecto de pre-entrega para el curso de Front-End JavaScript de Talento Tech.

## Descripción

Grind Street es una página web simple de una tienda de skateboards. El proyecto está realizado con HTML y CSS, siguiendo la estructura trabajada en clase.

## Tecnologías usadas

- HTML5
- CSS3
- Google Fonts
- Flexbox
- CSS Grid
- Media Queries
- Formspree para el formulario de contacto

## Estructura

- `index.html`: página principal.
- `styles.css`: estilos generales del sitio.
- `pages/contacto.html`: formulario de contacto.
- `img/`: imágenes y recursos visuales.

## Formulario

Para que el formulario envíe mensajes mediante Formspree, hay que reemplazar `REEMPLAZAR_ID` dentro de `pages/contacto.html` por el identificador del formulario creado en Formspree.


## Imágenes
Las fotografías utilizadas en la página son de Unsplash y se cargan desde sus URLs para mantener el proyecto simple y evitar archivos gráficos innecesarios en esta etapa.
